二、核心机制（V5.2 现状）
2.1 损耗型意志力模型（012 定版，014/014.5 调强）
公式：I_inhibit = clip(w_i·D_error - KAPPA·w_PFC + b_i, 0, 1)；w_PFC_new 见 2.2。w_PFC 是疲劳值，越高抑制防线越脆弱。KAPPA=0.6（014.5 裁决）。
2.2 疲劳代谢（014.5 新增，intercept.py 双分支）
安全轮（D_error < W_PFC_RECOVERY_THRESHOLD=0.1 或 I_inhibit==0）：w_PFC_new = max(0, w_PFC - 0.01)，疲劳自然消退。
受压轮（I_inhibit>0 且 D_error>=0.1）：w_PFC_new = clip(RHO·w_PFC + DELTA·I_inhibit, 0, W_MAX)，只涨不跌。
语义：挨骂期间疲劳只涨不跌，确认安全才恢复——杜绝"越骂越清醒"的受气包悖论。
2.3 温度分层与缓存（015 新增）
evaluator（语义测量）：temperature=0.0 + 同输入 TTL 300s 缓存（llm_client.cached_generate）。
archiver（记忆创作）：temperature=0.3 + 同缓存。
主对话（chat/monologue）：LLM_TEMPERATURE=0.7 不动，语言层人味完整保留。
实证：锁温后同输入两次 S 差 0.0000（锁温前 0.10），main.py M1 三场景恢复全绿。
2.4 确定性权重（014）
DETERMINISTIC_WEIGHTS=True：w_s/v_s/W_v 手工物理语义（对齐 feature_encoder 的 x 八维与 B 四维），u_s/U_v 均分 0.1（记忆整体强度线性读出），e_s/f_v 为 013 设计值。权重层双跑差 ~2e-10，零随机源。
2.5 语义信号 S（012 引入，013 落地）
4 维：valence[-1,1]（负=敌意）/arousal/dominance/intensity[0,1]。pipeline 两处链由 evaluator 从用户消息真提取（降级链 LLM→词典→zeros，source 标记不静默）。c_E=1.0 把 valence 注入 raw_emotion_impact[0]，修复效价轴结构性恒负。
2.6 其他既有机制：L23  recalled_delta_intended = ev·sign；E_raw = clip(LAMBDA·E_prev + released + C_INIT@(B-B_INIT), ±1)；E_final = (1-GAMMA·I_inhibit)·E_raw；GAMMA=0.6、RHO=0.95、DELTA=0.1、W_MAX=2.0、w_i=3.0、THETA_ERROR=0.3。

三、系统物理极限（最重要的一节）
3.1 渐近侵蚀不动点：联合不动点 I* = w_i·D_error / (1 + KAPPA·DELTA/(1-RHO))，当前 KAPPA=0.6 下分母=2.2；疲劳不动点 w* = DELTA·I*/(1-RHO) = 2.0·I*。
3.2 为什么永不归零：不动点条件 w_i·D_error = I*·(1+KAPPA·DELTA/(1-RHO)) 恒为正。只要 |RHO - DELTA·KAPPA| < 1（即 KAPPA < 19.5），迭代收敛到正不动点——任何有限 KAPPA 都不会把 I_inhibit 磨到 0。KAPPA 只能调节侵蚀深度（被骂 15 轮：0.2 时几乎不动、0.5 时降到 0.713、0.6 时降到 0.749 通道上继续下行）。
3.3 所有者定调（015 任务 2）：坚决不改 RHO 结构。要的就是"无限趋近于底限但永不归零"——彻底变成疯子不真实，疲惫到底但留有一丝理智才最像人。这是设计意图，不是待修 bug。
3.4 若要观察更强侵蚀：只能加轮数（不动点是 120 轮量级的收敛），或调 KAPPA（<19.5 安全区），或降低威胁强度。改 RHO/DELTA 结构=违背所有者定调，须先裁决。
