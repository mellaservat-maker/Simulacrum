2. archiver.py 中 organize_narrative 函数完整原文

    def organize_narrative(self, records: List[Dict[str, Any]]) -> MemoryPackage:
        # 【桩】此处未来替换为 LLM 整理，当前为占位实现
        seq = len(self._packages) + 1
        round_ids = [str(r.get("round_id", "")) for r in records]
        raw_pointer = "-".join(round_ids)

        # 关键词：取前 2 条记录 user_input 的前 4 个字
        keywords = []
        for r in records[:2]:
            text = r.get("user_input", "")
            if text:
                keywords.append(text[:4])
        keywords = keywords[:3]

        # 叙事字段：桩占位
        first_user = records[0].get("user_input", "") if records else ""
        last_user = records[-1].get("user_input", "") if records else ""
        count = len(records)

        narrative_cause = f"桩：起因是用户在第{round_ids[0]}轮说'{first_user}'"
        narrative_trigger = f"桩：触发点是{count}轮对话积累"
        narrative_consequence = f"桩：后果是到第{round_ids[-1]}轮用户说'{last_user}'"
        narrative_evaluation = f"桩：我的评价是中性，共{count}轮"
        narrative_emotion = "桩：我的情绪是 neutral（占位）"
        narrative_thought = f"桩：我的想法是这{count}轮可以归纳为一段记忆"

        return MemoryPackage(
            seq=seq,
            emotion_value=0.5,
            emotion_polarity="neutral",
            keywords=keywords,
            raw_pointer=raw_pointer,
            narrative_cause=narrative_cause,
            narrative_trigger=narrative_trigger,
            narrative_consequence=narrative_consequence,
            narrative_evaluation=narrative_evaluation,
            narrative_emotion=narrative_emotion,
            narrative_thought=narrative_thought,
        )

4. 任务 4 的四个逐条回答

问题 1：llm_client.py 现在对外暴露的接口是什么？

两个对外接口：

1. 类 MockLLM
   - 方法：generate(self, prompt)
   - 参数：prompt (str)
   - 返回值：str，格式为 "[MOCK] 收到 prompt，长度 {len(prompt)}"
   - 说明：Mock 实现，不接真实 LLM

2. 函数 get_llm()
   - 参数：无
   - 返回值：MockLLM 实例
   - 说明：全局单例式的工厂函数，当前每次返回新的 MockLLM 实例

没有配置 API key 的参数、没有切换模型的参数、没有多种 LLM 子类。


问题 2：archiver.py 的 organize_narrative 现在输入什么、输出什么？

输入：records: List[Dict[str, Any]]
  - 列表，每个元素是一轮对话的记录 dict
  - dict 内至少包含 round_id、user_input 等字段（由调用方保证）

输出：MemoryPackage
  - 一个完整的 MemoryPackage 对象，包含数值层和叙事层全部字段
  - 当前所有字段都是用固定逻辑拼接的桩值（emotion_value=0.5, polarity="neutral" 等）
  - 函数顶部有注释 "【桩】此处未来替换为 LLM 整理，当前为占位实现"


问题 3：全项目中有哪些地方调用 LLM？

2 处实际调用，都在 pipeline.py：
  - pipeline.py 第 115 行（run_scenario 函数内）：llm_output = get_llm().generate(prompt)
  - pipeline.py 第 249 行（run_turn 函数内）：llm_output = get_llm().generate(prompt)

1 处 import：
  - pipeline.py 第 28 行：from llm_client import get_llm

其余地方（archiver / state / config 等）均不调用 LLM。
archiver.py 的 organize_narrative 是纯字符串拼接的桩，不调 LLM。


问题 4：是否有任何地方已经预留了"配置 API key"或"切换模型"的位置？

无。

llm_client.py 只有 MockLLM 和 get_llm()，没有 API key 参数、没有模型名称参数、
没有配置文件读取、没有环境变量读取、没有多模型切换逻辑。
config.py 里也没有任何 LLM 相关配置常量。
pipeline.py 里也只是直接调 get_llm().generate(prompt)，没有传任何配置参数。
